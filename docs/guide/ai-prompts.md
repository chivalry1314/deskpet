# AI 生成动画素材

DeskPet 编辑器内置了针对 AI 生图工具的提示词模板，帮助你用一张角色图生成循环动画素材。

## 适用场景

- 你只有一张角色静态图，想生成待机动画、点击反馈动画等。
- 你不懂动画制作，但会使用豆包、即梦、Runway 等 AI 工具。
- 你想快速让宠物有丰富的动作状态。

## 基本流程

```
准备角色图 → 复制提示词 → 到 AI 工具生成 GIF/MP4 → 回传编辑器自动拆帧 → 保存
```

## 操作步骤

### 1. 打开提示词面板

在编辑器左侧点击 **状态管理**，然后点击 **✨ AI 生成提示词** 按钮。

![AI 提示词按钮](/images/ai-prompt-button.png)

### 2. 选择并复制提示词

提示词按「通用」「猫」「狗」分类，选择适合你角色的提示词，点击 **复制提示词**。

![提示词面板](/images/ai-prompt-panel.png)

### 3. 在 AI 工具中生成动画

以豆包或即梦为例：

1. 打开 AI 工具的图片/视频生成功能。
2. 上传你的角色图作为参考图。
3. 粘贴复制的提示词。
4. 选择生成 **GIF** 或 **MP4**（推荐 GIF，文件小、兼容性好）。
5. 等待生成并下载。

> 提示词已要求「纯白背景、角色居中、不加文字和水印、不改变角色外观」，但不同 AI 工具理解可能有偏差，生成后建议检查。

### 4. 上传回编辑器拆帧

1. 回到 DeskPet 编辑器，进入目标状态（如 `idle` 或 `clicked`）。
2. 把下载的 GIF/MP4 直接拖到上传区，或点击上传区选择文件。
3. 编辑器会自动拆帧，并按顺序排列。

![GIF 自动拆帧](/images/gif-split.svg)

### 5. 调整循环方式

AI 生成的视频首尾帧往往不能无缝衔接，建议：

- 对于待机、走路等循环状态，在状态卡片里把 **循环方式** 设为 **往返循环**。
- 这样动画播到末尾后会倒放回去，消除跳变感。

![设置往返循环](/images/pingpong-loop.svg)

### 6. 预览并保存

切换到 **实时预览**，查看动画效果。满意后点击 **保存到本地**。

## 提示词模板说明

编辑器内置的提示词模板覆盖了常见状态：

| 状态 | 说明 |
|---|---|
| 待机动画（idle） | 轻微呼吸、眨眼，循环播放 |
| 点击反应（clicked） | 被点击后开心跳一下、冒爱心等，单次播放 |
| 行走动画（walk） | 走路或蹦跳，循环播放 |
| 键盘反应（typing） | 敲键盘动作，头顶冒出按键字母气泡 |
| 睡觉（sleep） | 趴下闭眼、轻微呼吸 |
| 玩耍（play） | 摇尾巴、转圈、扑空气 |
| 伸懒腰/抓痒（scratch） | 伸懒腰或抓痒，单次播放 |

针对猫和狗，还有专门的「猫待机」「猫被点击」「狗待机」「狗被点击」等模板。

## 注意事项

- **背景**：提示词要求纯白背景，方便编辑器自动去除白底（上传区默认开启「自动去白底」）。
- **角色一致性**：AI 生成多帧时角色可能略有变化，尽量选择能固定角色的 AI 工具或参考图模式。
- **帧数**：拆帧后帧数可能很多，建议保留 5~20 帧，太多会影响性能。
- **FPS**：GIF 自带帧间隔，编辑器会尽量自动推断 FPS；如不准，可手动修改。
