# 使用编辑器创建宠物

编辑器是 DeskPet 的核心功能之一。你可以上传自己的角色图片，为不同状态配置动画帧，最后保存到本地或导出 `.pet` 文件分享。

## 进入编辑器

在宠物管理器中，点击右上角 **创建新宠物**，或在已有宠物右侧点击 **编辑**。

![编辑器入口](/images/editor-open.png)

## 编辑器界面概览

编辑器左侧有四个标签页：

| 标签 | 作用 |
|---|---|
| **基本信息** | 宠物名称、版本、作者、窗口尺寸、缩放 |
| **状态管理** | 添加/删除状态、上传帧图、设置 FPS 与循环 |
| **行为配置** | 待机时间、移动速度、随机游走、拖拽、点击响应等 |
| **实时预览** | 按当前设置播放动画，查看实际效果 |

![编辑器界面概览](/images/editor-layout.png)

## 第一步：填写基本信息

1. 点击左侧 **基本信息**。
2. 输入：
   - **宠物名称**：显示在管理器中的名字（建议用中文或英文）。
   - **版本**：如 `1.0`。
   - **作者**：你的名字。
   - **窗口宽度 / 高度**：宠物悬浮窗的像素尺寸，通常 150×150 即可。
   - **缩放**：整体放大或缩小，例如 `1.0` 为原始大小，`1.5` 为 1.5 倍。

![填写基本信息](/images/editor-basic-info.png)

## 第二步：上传状态帧图

1. 点击左侧 **状态管理**。
2. 默认已有 `idle`（待机）状态，至少需要给 idle 上传一帧图。
3. 在 `idle` 状态卡片中，点击或拖拽图片到上传区。

![上传状态帧图](/images/editor-upload-frames.png)

### 支持的素材格式

- **PNG 帧图**：推荐。透明背景最佳。
- **GIF**：自动拆成多帧。
- **MP4 / 视频**：自动拆成多帧（依赖浏览器能力，建议片段短于 5 秒）。

### 上传多张帧图

一次选中多张 PNG，编辑器会按文件名顺序排列成动画帧。拖动后的小缩略图显示顺序，即为播放顺序。

![多帧排列](/images/editor-frames-order.png)

### 删除单帧

鼠标悬停在某帧缩略图上，点击右上角出现的红色 **×** 即可删除。

## 第三步：配置状态参数

每个状态卡片顶部有 3 个参数：

| 参数 | 说明 | 建议 |
|---|---|---|
| **FPS** | 每秒播放多少帧 | 待机 6~8，走路 10~14，点击反馈 10~24 |
| **循环** | 是否一直循环播放 | 待机、走路选「循环」；点击反应选「单次」 |
| **循环方式** | 直接循环 / 往返循环 | 若 AI 生成的首尾帧跳变明显，选「往返循环」 |

如果状态设为「单次播放」，则会出现 **结束后切换**，默认回到 `idle`。

![状态参数配置](/images/editor-state-config.png)

## 第四步：添加更多状态

常见状态：

| 界面显示 | 内部标识 | 作用 |
|---|---|---|
| 待机 | `idle` | 默认状态，必须有 |
| 点击 | `clicked` | 被点击时的反馈 |
| 游走 | `walk` | 走路或移动 |
| 睡觉 | `sleep` | 睡觉 |
| 打字 | `typing` | 敲击键盘时触发（按键监听） |
| 玩耍 | `play` | 玩耍动作 |
| 进食 | `eat` | 进食动作 |
| 喝水 | `drink` | 喝水动作 |
| 开心 | `happy` | 开心表情/动作 |

点击 **+ 添加状态**，在弹出的对话框中从下拉框选择预设状态（如「游走」「打字」「睡觉」），点击 **添加** 即可创建。所有状态在界面上显示中文，内部仍使用英文标识，方便分享和识别。

![添加状态](/images/editor-add-state.png)

> `idle`（待机）状态是必需的，不能删除。状态名称只能从预设下拉框中选择，不支持自定义名称。

## 第五步：配置行为

点击左侧 **行为配置**，可调整宠物在桌面上的行为：

| 配置项 | 说明 |
|---|---|
| **待机最短时间 / 最长时间** | 两次随机行为之间的间隔秒数范围 |
| **移动速度** | 随机游走时的像素速度 |
| **点击响应状态** | 点击宠物时切换到哪个状态，默认「点击」，从已有状态下拉选择（界面显示中文） |
| **可被拖拽** | 是否允许用鼠标拖动宠物位置 |
| **待机结束后随机切换状态** | 勾选想要的状态，待机结束后会随机从中挑选一个播放。状态名称显示中文；勾选「游走」时，会额外出现「游走范围」选项 |
| **游走范围** | 仅勾选「游走」时出现。选择「全屏走动」会真实移动宠物窗口；选择「原地走动」只播放游走动动画，窗口位置保持不变 |

![行为配置](/images/editor-behavior-config.png)

> **注意**：修改行为配置后，需要返回管理器点击 **停止** 再重新 **运行** 宠物才会生效，当前运行的宠物不会实时更新。

## 第六步：实时预览

点击左侧 **实时预览**，选择要预览的状态，即可在右侧看到动画效果。

![实时预览](/images/editor-preview.png)

## 第七步：保存到本地

确认无误后，点击顶部 **保存到本地** 按钮。编辑器会：

1. 把图片按状态命名保存到本地数据目录。
2. 生成 `manifest.json` 配置文件。
3. 返回宠物管理器。

![保存到本地](/images/editor-save.png)

保存成功后，管理器列表里会出现你的新宠物，点击 **运行** 即可让它出现在桌面。

## 使用 AI 生成动画素材（推荐）

如果你只有一张角色图，可以到豆包、即梦等 AI 工具生成动画：

1. 在编辑器「状态管理」点击 **✨ AI 生成提示词**。
2. 复制对应状态的提示词。
3. 在 AI 工具中上传你的角色图，粘贴提示词，生成 GIF 或 MP4。
4. 回到编辑器，把生成的文件直接拖到上传区，自动拆帧。

更详细的提示词用法，请参考 [AI 生成动画素材](/guide/ai-prompts)。
