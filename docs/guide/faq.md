# 常见问题

## 安装与启动

### Q: Windows 安装时被 SmartScreen 拦截怎么办？

DeskPet 目前未购买代码签名证书，Windows 可能提示未知发布者。请点击提示上的「更多信息」→「仍要运行」。

![SmartScreen 放行](/images/windows-smartscreen.svg)

### Q: macOS 提示「无法打开，因为无法验证开发者」？

这是因为没有 Apple 开发者签名。请右键应用图标 →「打开」，或在终端执行：

```bash
xattr -cr /Applications/DeskPet\ Engine.app
```

### Q: Linux AppImage 双击没反应？

请确保文件有执行权限：

```bash
chmod +x "DeskPet Engine_0.1.0_amd64.AppImage"
./"DeskPet Engine_0.1.0_amd64.AppImage"
```

## 创建与编辑宠物

### Q: 上传图片后宠物显示白边？

编辑器默认开启「自动去白底」。如果去白底效果不理想，请在上传前把图片背景处理为透明 PNG，或关闭自动去白底后手动处理。

### Q: 动画播放速度太快或太慢？

调整状态卡片中的 **FPS** 数值：

- FPS 越大，动画越快。
- FPS 越小，动画越慢。

### Q: 循环动画首尾跳变明显？

在状态卡片中把 **循环方式** 改为 **往返循环**。这样动画播到末尾后会倒放回去，消除跳变。

### Q: 点击宠物没有反应？

请检查：

1. 是否给 `clicked` 状态上传了帧图。
2. 行为配置中的 **点击响应状态** 是否填写正确（默认 `clicked`）。
3. 设置中是否开启了 **鼠标穿透**（开启后无法点击）。

### Q: 按键不会触发动画？

请检查：

1. 设置中是否开启 **按键触发动画**。
2. 是否有 `typing` 状态且帧图不为空。
3. 该功能当前仅在 Windows 平台有效。

## 运行与管理

### Q: 宠物窗口找不到或跑出了屏幕？

在管理器中点击「停止」再重新「运行」，宠物会重新出现在当前屏幕工作区中央。

### Q: 关闭主窗口后宠物还在运行？

这是设计行为。DeskPet 关闭主窗口后默认最小化到系统托盘，宠物继续运行。要彻底退出，请在系统托盘图标右键 → **退出**。

### Q: 如何备份自己的宠物？

在管理器中选择宠物，点击 **导出**，把 `.pet` 文件保存到安全位置。也可以直接备份本地数据目录：

- Windows: `%APPDATA%/DeskPet/`
- macOS: `~/Library/Application Support/DeskPet/`
- Linux: `~/.config/DeskPet/`

### Q: 导入 .pet 失败？

请检查 `.pet` 文件是否完整：

1. 用压缩工具打开 `.pet`（它本质是 ZIP）。
2. 确认内部有 `manifest.json`。
3. 确认 `manifest.json` 中引用的帧图文件名都存在。

## 性能与兼容性

### Q: 运行宠物后 CPU 占用较高？

- 减少动画帧数（每状态建议 5~20 帧）。
- 降低 FPS。
- 减少窗口尺寸（如从 300×300 改为 150×150）。

### Q: 视频上传后无法拆帧？

视频拆帧依赖浏览器环境，部分格式可能不支持。建议：

- 使用 MP4 格式，H.264 编码。
- 视频片段控制在 5 秒以内。
- 若失败，可先用其他工具把视频转为 GIF 或 PNG 序列再上传。

## 其他

### Q: 可以自定义数据目录到网盘实现同步吗？

可以。在管理器设置中点击 **更改目录**，选择网盘同步文件夹（如 OneDrive、iCloud、坚果云）。建议切换时选择「迁移已有宠物」。
