# 宠物管理

宠物管理器是 DeskPet 的主界面，用于查看本地宠物库、运行、编辑、导入、导出和删除宠物。

## 打开管理器

启动 DeskPet 后默认就是管理器。如果正在运行宠物，可通过系统托盘右键菜单「显示主窗口」打开。

![宠物管理器](/images/manager-overview.png)

## 导入 .pet 文件

`.pet` 是 DeskPet 的宠物打包格式，本质是一个 ZIP 压缩包，后缀改为 `.pet`。你可以从网上下载别人分享的 `.pet` 文件，然后导入使用。

操作步骤：

1. 在管理器右上角点击 **导入 .pet**。
2. 在文件选择对话框中选择 `.pet` 文件。
3. 如果列表中已有同名宠物，软件会弹出重命名对话框，让你为导入的宠物指定一个新名称。
4. 导入成功后，宠物会出现在列表中。

![导入 .pet](/images/import-pet.svg)

> 导入不会覆盖已有同名宠物，遇到同名时需要先填入新名称再继续。

## 导出 .pet 文件

想把自己做的宠物分享给朋友？

1. 在宠物列表中点击该宠物右侧的 **导出** 按钮。
2. 软件会把宠物打包成 `.pet` 文件，保存到数据目录的 `exports` 文件夹下，并自动打开文件夹。

![导出 .pet](/images/export-pet.svg)

导出的文件可以直接发送给其他人，对方用 DeskPet 导入即可运行。

## 编辑已有宠物

点击宠物右侧的 **编辑**，会重新进入编辑器，所有图片和配置都可以再次修改。

> 修改后保存，会覆盖原宠物数据。

## 删除宠物

点击宠物右侧的 **删除**，确认后即可删除本地宠物及其所有素材。

> 删除后无法恢复，如需保留，请先导出备份。

## 本地数据目录

DeskPet 把所有数据存放在本地以下路径：

| 系统 | 路径 |
|---|---|
| Windows | `%APPDATA%/DeskPet/` |
| macOS | `~/Library/Application Support/DeskPet/` |
| Linux | `~/.config/DeskPet/` |

目录结构：

```
DeskPet/
├── pets/                  # 宠物文件夹
│   ├── 橘猫小咪/
│   │   ├── manifest.json
│   │   └── *.png
│   └── ...
├── exports/               # 导出的 .pet 文件
├── settings.json          # 全局设置
└── pets.json              # 宠物索引
```

## 更改数据目录

在管理器右上角点击 **设置** → **数据目录** → **更改目录**，可以切换到自定义位置。例如把数据目录放到外置硬盘或云同步盘，实现跨设备同步。

切换时可选择是否迁移已有宠物：

- **迁移**：把旧目录里的宠物复制到新目录。
- **不迁移**：只切换目录，旧宠物仍保留在原处。

![更改数据目录](/images/change-data-dir.svg)

> **重要**：每次升级软件前，请先在管理器中选择宠物点击 **导出**，把 `.pet` 文件备份到安全位置；或手动备份整个数据目录。升级安装可能会覆盖旧数据，导出 `.pet` 是最稳妥的备份方式。
