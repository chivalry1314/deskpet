# 快速上手

本指南将带你用内置的 Live2D 示范猫和示例宠物，在 5 分钟内跑起第一只桌宠。

## 1. 启动软件

安装并打开 DeskPet Engine，进入宠物管理器。你会看到以下界面：

![宠物管理器界面](/images/manager-overview.png)

界面说明：

- **左侧/上方**：宠物列表，包括「Live2D 示范猫」和你自己创建的宠物。
- **右侧按钮**：运行、编辑、导出、删除。
- **右上角**：导入 `.pet`、创建新宠物、设置。

## 2. 运行内置 Live2D 示范猫

点击「Live2D 示范猫」右侧的 **运行** 按钮，桌面会弹出一个透明悬浮窗，一只猫出现在屏幕中央。

![运行 Live2D 示范猫](/images/run-live2d.svg)

## 3. 与宠物互动

在宠物窗口上：

- **鼠标左键点击**：触发配置的「点击响应状态」（默认「点击」）。
- **按住拖拽**：把宠物移动到屏幕任意位置。
- **右键菜单**：可「水平翻转」或「关闭宠物」。

> 在编辑器里修改配置后，需要回到管理器点击 **停止** 再重新 **运行** 才会生效。

![宠物右键菜单](/images/viewer-context-menu.svg)

## 4. 导入示例宠物（可选）

仓库里的 `examples/demo-cat.pet` 是一个帧图宠物示例。你可以：

1. 在管理器右上角点击 **导入 .pet**。
2. 选择 `demo-cat.pet` 文件。
3. 导入成功后，列表里会出现「橘猫小咪」。
4. 点击 **运行** 即可。

![导入 .pet 文件](/images/import-pet.svg)

## 5. 创建自己的宠物

想用自己的角色图？点击右上角 **创建新宠物**，进入编辑器：

![创建新宠物入口](/images/create-pet-button.png)

编辑器会引导你完成：

1. 填写宠物名称、作者、窗口尺寸。
2. 在「状态管理」里上传 idle（待机）等状态的图片。
3. 调整 FPS、循环方式。
4. 点击「保存到本地」。

更详细的步骤请参考 [使用编辑器创建宠物](/guide/create-pet)。
