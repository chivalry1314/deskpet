# 运行桌宠

在宠物管理器中，找到想运行的宠物，点击右侧 **运行** 按钮，桌面就会弹出宠物的透明悬浮窗。

![运行宠物](/images/run-pet.png)

## 宠物窗口特性

宠物运行窗口是一个无边框、透明背景的悬浮窗：

- **始终置顶**：默认位于所有窗口之上，不会被其他软件遮挡。
- **不在任务栏显示**：只在系统托盘区显示图标。
- **鼠标可穿透**：开启「鼠标穿透」后，点击宠物空白处可穿透到下方窗口。
- **可拖拽**：按住宠物拖动即可改变位置。

## 与宠物互动

| 操作 | 效果 |
|---|---|
| 左键点击 | 触发配置的「点击响应状态」（默认「点击」/ `clicked`，可在编辑器行为配置中选择） |
| 按住拖拽 | 移动宠物位置 |
| 右键点击 | 打开宠物菜单：水平翻转、恢复自动朝向、关闭宠物 |
| 按键（Windows） | 空格/回车/方向键/WASD/数字键 1-5 会触发「打字」/ `typing` 状态或点击反馈 |

> **配置生效时机**：在编辑器中修改宠物配置后，需要返回管理器点击 **停止** 再重新 **运行**，当前运行的宠物不会实时更新。

![宠物右键菜单](/images/viewer-context-menu.svg)

## 右键菜单说明

在宠物窗口上点击右键，会弹出菜单：

- **水平翻转**：手动把宠物镜像显示。
- **恢复自动朝向**：取消手动翻转，恢复根据鼠标位置自动转向。
- **关闭宠物**：关闭当前宠物窗口，回到管理器。

## 关闭主窗口 vs 退出软件

点击管理器窗口右上角关闭按钮时，DeskPet 默认**最小化到系统托盘**，不会真正退出。宠物会继续运行。

要彻底退出：

- 在系统托盘图标上右键 → **退出**。
- 或点击菜单中的 **退出**。

![系统托盘菜单](/images/system-tray-menu.svg)

## 运行设置

在管理器右上角点击 **设置**，可以调整全局运行参数：

| 设置项 | 说明 |
|---|---|
| 宠物透明度 | 悬浮窗整体不透明度 |
| 宠物始终置顶 | 是否保持窗口最前 |
| 鼠标穿透 | 是否不响应点击/拖拽（适合纯观赏） |
| 看向鼠标 | 宠物根据鼠标左右位置自动翻转朝向 |
| 按键触发动画 | 敲击键盘时是否触发 `typing` 状态 |

详细说明请参考 [设置说明](/guide/settings)。

## 同时运行多只宠物

当前版本同一时间只支持运行一个宠物窗口。如果想换一只宠物，先点击**停止**，再运行另一只。

> 多宠物同时运行已列入第二阶段计划，敬请期待。
